# Support and questions

This repository is the public site and content source for the Amadeus Open Source Community and OSPO.

## General questions

- Open a GitHub issue for a public website bug, content correction or documentation question once the repository is public.
- For general OSPO questions or a private context, contact [opensource@amadeus.com](mailto:opensource@amadeus.com).
- For contribution proposals, follow the Open Source Board process rather than placing confidential invention material in a public issue.

## What not to put in a public issue

Do not include:

- security vulnerabilities;
- credentials or personal data;
- private repository names or internal URLs;
- invention-disclosure material;
- confidential business or technical information; or
- unreleased metrics.

For security concerns, use [SECURITY.md](SECURITY.md).
